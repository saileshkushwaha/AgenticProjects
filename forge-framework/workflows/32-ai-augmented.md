# Workflow 32: AI-Augmented Development

**Duration**: 2-8h | **Outputs**: AI integration plan, tool selection, adoption roadmap

## Trigger
- AI tool adoption, coding assistant integration
- AI-assisted testing, AI code review

## Steps

### Step 1: Needs Assessment
Identify AI opportunities (coding, testing, review, documentation). Assess team readiness.
**Time**: 1-2h.

### Step 2: Tool Evaluation
Evaluate AI tools (Copilot, Cursor, Cody, custom agents). Compare features and costs.
**Time**: 2-4h.

### Step 3: Integration Planning
Define integration approach. Plan pilot. Set success metrics.
**Time**: 1-2h.

### Step 4: Pilot Implementation
Run pilot with selected team. Gather feedback. Measure productivity.
**Time**: 2-4h.

### Step 5: Policy and Guidelines
Define AI usage policies. Address security and IP concerns. Create guidelines.
**Time**: 1-2h.

### Step 6: Rollout and Training
Train team. Roll out tools. Measure adoption and impact.
**Time**: 1-2h.

## Quality Gates

| Gate | Criteria |
|------|----------|
| QG1 | Needs assessed |
| QG2 | Tools evaluated |
| QG3 | Integration planned |
| QG4 | Pilot complete |
| QG5 | Policies defined |
| QG6 | Rollout complete |

## Output
Use: `templates/ai-augmented-plan.md` | Capability: `capabilities/ai-augmented.md`

## Anti-Patterns

1. **Security as afterthought** — Adding security late
2. **Tool overload** — Too many tools without integration
3. **No automation** — Manual processes in CI/CD
4. **Ignoring compliance** — Not meeting regulatory requirements

## Edge Cases

- Legacy systems → Use incremental security improvements
- No security team → Use automated tools
- Compliance conflicts → Consult legal team
