# Workflow 27: Knowledge Management

**Duration**: 2-8h | **Outputs**: Knowledge base, lessons learned, onboarding docs

## Trigger
- Knowledge base creation, lessons learned documentation
- Onboarding documentation, tribal knowledge capture

## Steps

### Step 1: Knowledge Audit
Identify knowledge gaps. Catalog existing documentation. Interview experts.
**Time**: 1-2h.

### Step 2: Content Planning
Define topics and structure. Assign authors. Set priorities.
**Time**: 1-2h.

### Step 3: Content Creation
Write documentation. Create diagrams. Record videos if needed.
**Time**: 2-4h.

### Step 4: Review and Organization
Review for accuracy. Organize in knowledge base. Add tags and search.
**Time**: 1-2h.

### Step 5: Maintenance Process
Define update schedule. Assign ownership. Set review cadence.
**Time**: 30-60 min.

### Step 6: Adoption and Feedback
Promote usage. Gather feedback. Iterate on content.
**Time**: 30-60 min.

## Quality Gates

| Gate | Criteria |
|------|----------|
| QG1 | Knowledge gaps identified |
| QG2 | Content planned |
| QG3 | Content created |
| QG4 | Review and organization complete |
| QG5 | Maintenance process defined |
| QG6 | Adoption tracked |

## Output
Use: `templates/knowledge-base.md` | Capability: `capabilities/knowledge-management.md`

## Anti-Patterns

1. **Ignoring stakeholders** — Not engaging key stakeholders
2. **One-way communication** — Not gathering feedback
3. **Scope creep** — Uncontrolled expansion
4. **No documentation** — Not documenting decisions

## Edge Cases

- Conflicting stakeholder needs → Facilitate prioritization
- No stakeholder availability → Use async communication
- Resistance to change → Provide training and support
