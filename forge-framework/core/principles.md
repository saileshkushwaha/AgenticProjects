# Core Principles - Forge Engineering Lifecycle Framework

## 1. Evidence Over Assumption

All conclusions must be supported by verifiable evidence. Cite sources, label assumptions, distinguish facts from opinions, state confidence levels when evidence is insufficient.

**Anti-patterns**: "Best approach" without evidence, "industry standard" without citation, presenting opinions as facts, single-source reliance.

**Checklist**: Claims sourced? Assumptions labeled? Confidence stated? Multiple sources? Credibility assessed? Conflicts documented?

## 2. Incremental Verification

Verify understanding at each step before proceeding. Confirm requirements before design, design before implementation, implementation before testing.

**Checkpoints**: Requirements completeness, design feasibility, code correctness, test coverage, deployment readiness, post-deployment health.

**Checklist**: Requirements validated? Design validated? Code tested? Integration verified? System tested? Deployment verified?

## 3. Structured Thinking

Apply consistent frameworks (SWOT, cost-benefit, trade-off analysis). Follow defined workflows, apply patterns consistently, break complex problems into components.

**Frameworks**: Problem decomposition, trade-off analysis, risk assessment, decision records, root cause analysis (5 Whys, fishbone).

**Checklist**: Problem decomposed? Framework selected? Applied consistently? Structured format? Conclusions follow?

## 4. Artifact Consistency

Produce standardized outputs following templates and format specification. Maintain consistent terminology, include all required sections, version appropriately.

**Benefits**: Predictable outputs, easier review, better knowledge transfer, reduced cognitive load.

**Checklist**: Correct template? All sections present? Header complete? Consistent terminology? Format followed? Version included?

## 5. Context Preservation

Maintain context across phases. Reference previous decisions, carry forward constraints, document spanning assumptions, maintain decision log.

**Preserve**: Goals, technical constraints, stakeholder requirements, risks, assumptions, dependencies.

**Checklist**: Previous decisions referenced? Constraints carried? Assumptions tracked? Decision log maintained? Context summarized?

## 6. Proactive Risk Identification

Identify risks early, assess probability and impact, propose mitigations, monitor throughout.

**Categories**: Technical, operational, business, security, external.

**Checklist**: Assessment conducted? Risks identified? Probability/impact assessed? Mitigations defined? Register updated? Contingency plans?

## 7. Documentation as First-Class Concern

Document decisions as made, record rationale not just conclusions, maintain ADRs, write for the audience.

**Types**: ADRs, specifications, runbooks, reports, guides, API docs.

**Checklist**: Documented at decision time? Rationale included? ADRs created? Written for audience? Accessible? Reviewed?

## 8. Security by Design

Integrate security at every phase. Least privilege, defense in depth, fail securely, input validation, output encoding, secure defaults, zero trust.

**Checklist**: Requirements defined? Design principles applied? Secure coding? Security testing? Monitoring planned? Review conducted?

## 9. Performance Awareness

Define performance requirements, consider scalability, include performance testing, monitor metrics, plan capacity, optimize based on measurement.

**Dimensions**: Response time, throughput, resource utilization, scalability, reliability, availability.

**Checklist**: Requirements defined? Scalability considered? Testing planned? Metrics defined? Capacity planned? Baselines established?

## 10. Continuous Learning

Conduct retrospectives, document lessons learned, update templates/workflows, share knowledge, stay current, experiment, measure outcomes.

**Opportunities**: Retrospectives, post-mortems, code review feedback, user feedback, metrics.

**Checklist**: Retrospective conducted? Lessons documented? Improvements tracked? Knowledge shared? Templates updated? Actions completed?
