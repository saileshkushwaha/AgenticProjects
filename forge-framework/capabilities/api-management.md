# API Management Capability

## Definition
The ability to manage the full API lifecycle including versioning, deprecation, and developer experience.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can document APIs, follow guidelines |
| 2 | Competent | Can manage API versions, deprecation |
| 3 | Proficient | Can design API strategies, assess DX |
| 4 | Expert | Can design API platforms, governance |
| 5 | Master | Can establish organizational API management |

## Scope
**In Scope**: API inventory, versioning, deprecation, DX, analytics, documentation
**Out of Scope**: API business model (product management)

## Skills
- **Inventory**: API cataloging, documentation
- **Versioning**: Strategy, policy, migration
- **Deprecation**: Planning, communication, migration
- **DX**: Documentation, SDKs, sandbox, analytics

## Quality Criteria
- Inventory complete
- Versioning strategy defined
- Deprecation plan created
- DX assessed
