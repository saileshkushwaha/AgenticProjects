# Accessibility Capability

## Definition
The ability to assess and improve accessibility of software products.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run automated tools, identify obvious issues |
| 2 | Competent | Can conduct manual testing, document findings |
| 3 | Proficient | Can lead accessibility audits, plan remediation |
| 4 | Expert | Can design accessibility programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: WCAG compliance, automated/manual testing, remediation, VPAT
**Out of Scope**: Legal compliance (consult legal)

## Skills
- **Automated Testing**: axe, WAVE, Lighthouse
- **Manual Testing**: Keyboard, screen reader, contrast
- **Remediation**: Fix prioritization, implementation
- **Documentation**: VPAT, compliance reports

## Quality Criteria
- Automated testing complete
- Manual testing complete
- Remediation planned
- Compliance documented
