# Multi-Agent Coordination Capability

## Definition
The ability to design and coordinate multi-agent systems.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use single AI agents |
| 2 | Competent | Can coordinate simple multi-agent workflows |
| 3 | Proficient | Can design multi-agent architectures |
| 4 | Expert | Can design enterprise multi-agent systems |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: Agent design, orchestration, communication protocols
**Out of Scope**: AI model development (consult ML team)

## Skills
- **Decomposition**: Task breakdown, role assignment
- **Orchestration**: Workflow design, error handling
- **Communication**: Protocol design, message passing
- **Monitoring**: Performance tracking, optimization

## Quality Criteria
- Tasks decomposed
- Agents designed
- Orchestration planned
- Testing passed
