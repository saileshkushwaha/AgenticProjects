# Green Coding Capability

## Definition
The ability to write energy-efficient, carbon-aware code.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify obvious inefficiencies |
| 2 | Competent | Can apply green coding practices |
| 3 | Proficient | Can measure carbon footprint, optimize |
| 4 | Expert | Can design green coding programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: Carbon measurement, algorithm optimization, resource efficiency
**Out of Scope**: Hardware design (consult specialists)

## Skills
- **Measurement**: Carbon footprint tools, energy profiling
- **Optimization**: Algorithm efficiency, data transfer reduction
- **Awareness**: Green patterns, carbon-aware scheduling
- **Reporting**: Carbon savings, sustainability metrics

## Quality Criteria
- Baseline established
- Optimizations implemented
- Reduction measured
- Report complete
