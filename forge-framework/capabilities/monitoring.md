# Monitoring and Observability Capability

## Definition
The ability to design and implement monitoring and observability solutions.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use monitoring tools, read dashboards |
| 2 | Competent | Can configure alerts, create dashboards |
| 3 | Proficient | Can design monitoring strategies, define SLOs |
| 4 | Expert | Can design enterprise observability |
| 5 | Master | Can establish organizational monitoring |

## Scope
**In Scope**: Metrics, logs, traces, alerting, SLOs, dashboards
**Out of Scope**: Tool administration (consult ops)

## Skills
- **Instrumentation**: Metrics, logs, traces collection
- **Alerting**: Threshold design, notification routing
- **SLOs**: SLIs, error budgets, compliance
- **Visualization**: Dashboards, reports

## Quality Criteria
- Requirements defined
- Tools selected
- Alerts configured
- SLOs defined
