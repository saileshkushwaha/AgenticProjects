# Greenfield Development Capability

## Definition

The ability to execute a complete greenfield project from initial idea through deployment, orchestrating research, analysis, design, implementation, testing, and deployment phases.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can execute individual phases with guidance |
| 2 | Competent | Can chain 2-3 phases with some manual intervention |
| 3 | Proficient | Can execute full project with minimal intervention |
| 4 | Expert | Can handle complex projects with cross-phase optimization |
| 5 | Master | Can establish organizational greenfield practices |

## Scope

### In Scope
- Project initiation and charter creation
- Technology research and evaluation
- Requirements analysis and feasibility
- System architecture and design
- Full-stack implementation
- Testing and quality assurance
- Deployment and monitoring
- Post-launch iteration

### Out of Scope
- Legacy system migration (see Modernization capability)
- Hardware development (consult specialists)
- Legal/compliance review (consult legal)

## Assessment Criteria

### Level 1 (Novice)
- [ ] Can execute individual phases
- [ ] Understands phase dependencies
- [ ] Can follow the master workflow

### Level 2 (Competent)
- [ ] Can chain 2-3 phases
- [ ] Manages context between phases
- [ ] Produces quality artifacts

### Level 3 (Proficient)
- [ ] Can execute full project end-to-end
- [ ] Handles iterative refinement
- [ ] Manages context window effectively

### Level 4 (Expert)
- [ ] Handles complex multi-team projects
- [ ] Optimizes across phases
- [ ] Mentors others in greenfield development

### Level 5 (Master)
- [ ] Establishes organizational practices
- [ ] Creates domain-specific greenfield workflows
- [ ] Drives innovation in project delivery
