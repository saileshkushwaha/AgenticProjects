# Technical Debt Management Capability

## Definition
The ability to identify, assess, prioritize, and remediate technical debt.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify obvious technical debt |
| 2 | Competent | Can assess and document debt items |
| 3 | Proficient | Can prioritize and plan remediation |
| 4 | Expert | Can design debt prevention strategies |
| 5 | Master | Can establish organizational debt management |

## Scope
**In Scope**: Code debt, architecture debt, documentation debt, testing debt, infrastructure debt, security debt
**Out of Scope**: Financial debt (consult finance)

## Skills
- **Identification**: Code review, architecture analysis
- **Assessment**: Impact and effort estimation
- **Prioritization**: Risk-based prioritization
- **Remediation**: Refactoring, documentation, testing
- **Prevention**: Standards, reviews, automation

## Assessment Criteria
- [ ] Can identify technical debt
- [ ] Can assess severity and effort
- [ ] Can prioritize debt items
- [ ] Can create remediation plans
- [ ] Can design prevention strategies

## Quality Criteria
- Debt items cataloged with severity
- Remediation roadmap created
- Prevention strategy defined
- Debt trends tracked over time
