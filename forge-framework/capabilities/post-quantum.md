# Post-Quantum Security Capability

## Definition
The ability to assess and migrate to quantum-resistant cryptography.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify cryptographic assets |
| 2 | Competent | Can assess quantum vulnerability |
| 3 | Proficient | Can plan and implement PQC migration |
| 4 | Expert | Can design enterprise PQC programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: Crypto inventory, quantum risk, PQC migration, crypto-agility
**Out of Scope**: Cryptography research (consult specialists)

## Skills
- **Inventory**: Cryptographic asset cataloging
- **Assessment**: Quantum vulnerability analysis
- **Migration**: PQC algorithm selection, hybrid approach
- **Agility**: Crypto-agility by design

## Quality Criteria
- Inventory complete
- Risks assessed
- Migration planned
- Validation passed
