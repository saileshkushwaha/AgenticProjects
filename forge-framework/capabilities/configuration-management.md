# Configuration Management Capability

## Definition
The ability to manage environment configurations, secrets, and feature flags.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can manage basic configs, follow procedures |
| 2 | Competent | Can manage environments, track changes |
| 3 | Proficient | Can audit configs, manage secrets, feature flags |
| 4 | Expert | Can design config strategies, automation |
| 5 | Master | Can establish organizational config management |

## Scope
**In Scope**: Environment config, secrets management, feature flags, change tracking
**Out of Scope**: Infrastructure provisioning (see Deployment)

## Skills
- **Inventory**: Catalog all configuration items
- **Comparison**: Environment drift detection
- **Secrets**: Storage, rotation, access control
- **Feature Flags**: Lifecycle management, cleanup

## Quality Criteria
- Inventory complete
- Environments compared
- Secrets managed securely
- Changes tracked
