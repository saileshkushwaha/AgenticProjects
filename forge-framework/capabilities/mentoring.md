# Mentoring Capability

## Definition
The ability to guide and develop junior team members.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can answer questions, provide basic guidance |
| 2 | Competent | Can mentor juniors, provide feedback |
| 3 | Proficient | Can design development plans, track progress |
| 4 | Expert | Can design mentoring programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: Skill assessment, development plans, 1:1s, feedback
**Out of Scope**: Performance reviews, HR matters (consult HR)

## Skills
- **Assessment**: Skill gap identification
- **Planning**: Development path creation
- **Teaching**: Explanation, demonstration, guidance
- **Feedback**: Constructive, actionable, timely

## Quality Criteria
- Skills assessed
- Development plan created
- Sessions conducted
- Progress tracked
