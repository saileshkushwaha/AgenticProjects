# DevSecOps Capability

## Definition
The ability to integrate security into the DevOps pipeline.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run security tools, follow procedures |
| 2 | Competent | Can integrate security into CI/CD |
| 3 | Proficient | Can design security pipelines, compliance as code |
| 4 | Expert | Can design enterprise DevSecOps programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: SAST, DAST, SCA, secrets scanning, compliance as code
**Out of Scope**: Physical security (consult specialists)

## Skills
- **Pipeline Integration**: CI/CD security gates
- **Tooling**: SAST, DAST, SCA selection and config
- **Compliance**: Policy as code, audit trails
- **Monitoring**: Security monitoring, incident response

## Quality Criteria
- Security tools integrated
- Quality gates defined
- Compliance as code implemented
- Team trained
