# Data Migration Capability

## Definition
The ability to plan, execute, and validate data migrations between systems.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can execute simple migrations, follow procedures |
| 2 | Competent | Can plan migrations, map transformations |
| 3 | Proficient | Can design migration strategies, validate data |
| 4 | Expert | Can design complex migrations, handle edge cases |
| 5 | Master | Can establish organizational migration practices |

## Scope
**In Scope**: Schema mapping, ETL, validation, rollback planning
**Out of Scope**: Database administration (consult DBA)

## Skills
- **Analysis**: Source/target analysis, data profiling
- **Mapping**: Schema mapping, transformation design
- **Validation**: Reconciliation, integrity checking
- **Rollback**: Recovery planning, data preservation

## Quality Criteria
- Source analyzed and target designed
- Migration strategy defined
- Validation passed
- Rollback plan documented
