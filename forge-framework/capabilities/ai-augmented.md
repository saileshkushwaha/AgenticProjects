# AI-Augmented Development Capability

## Definition
The ability to integrate AI tools into the development workflow.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can use AI coding assistants |
| 2 | Competent | Can integrate AI into workflow |
| 3 | Proficient | Can design AI adoption strategies |
| 4 | Expert | Can design enterprise AI programs |
| 5 | Master | Can establish organizational practices |

## Scope
**In Scope**: AI coding assistants, testing, review, documentation
**Out of Scope**: AI model development (consult ML team)

## Skills
- **Tool Evaluation**: Feature comparison, ROI analysis
- **Integration**: Workflow design, pilot planning
- **Policy**: Usage guidelines, security, IP
- **Measurement**: Productivity metrics, adoption tracking

## Quality Criteria
- Needs assessed
- Tools evaluated
- Pilot complete
- Policies defined
