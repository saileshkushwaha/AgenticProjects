# Research Capability

## Definition

The ability to systematically gather, evaluate, and synthesize information to support engineering decisions.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can search for information but struggles with evaluation and synthesis |
| 2 | Competent | Can find and evaluate sources, produce basic research reports |
| 3 | Proficient | Can conduct thorough research, evaluate credibility, synthesize findings |
| 4 | Expert | Can design research methodology, resolve conflicts, provide actionable insights |
| 5 | Master | Can establish research practices, mentor others, handle novel domains |

## Scope

### In Scope
- Technology evaluation and comparison
- Best practices identification
- Competitive analysis
- Industry trend analysis
- Academic research synthesis
- Documentation and reference gathering
- Expert identification and consultation
- Source credibility assessment
- Benchmark analysis

### Out of Scope
- Implementation of researched solutions (see Implementation capability)
- Deep financial analysis (see Analysis capability)
- Legal research (consult legal experts)

## Skills

### Information Retrieval
- Systematic search strategies
- Source evaluation and credibility assessment
- Cross-referencing and triangulation
- Academic database navigation
- Technical documentation analysis
- Expert identification
- Trend analysis

### Technology Assessment
- Feature comparison and scoring
- Maturity evaluation (TRL scale 1-9)
- Community health assessment
- Ecosystem analysis
- Integration complexity evaluation
- Cost-benefit analysis
- Risk assessment

### Synthesis
- Pattern identification across sources
- Conflict resolution between sources
- Confidence level assessment
- Executive summary creation
- Recommendation formulation
- Knowledge gap identification

## Assessment Criteria

### Level 1 (Novice)
- [ ] Can perform basic web searches
- [ ] Can identify relevant sources
- [ ] Can summarize individual sources

### Level 2 (Competent)
- [ ] Can use systematic search strategies
- [ ] Can evaluate source credibility
- [ ] Can produce a basic research report
- [ ] Can compare 2-3 options on basic criteria

### Level 3 (Proficient)
- [ ] Can design a research methodology
- [ ] Can synthesize findings from multiple sources
- [ ] Can resolve conflicts between sources
- [ ] Can provide confidence levels for findings
- [ ] Can create actionable recommendations

### Level 4 (Expert)
- [ ] Can handle novel or ambiguous research questions
- [ ] Can identify knowledge gaps and propose investigations
- [ ] Can mentor others in research methods
- [ ] Can present findings to technical and non-technical audiences

### Level 5 (Master)
- [ ] Can establish organizational research practices
- [ ] Can design research frameworks for new domains
- [ ] Can evaluate and improve research methodologies
- [ ] Can synthesize across disciplines

## Inputs
- Research questions or objectives
- Domain context
- Existing knowledge base
- Stakeholder requirements
- Time and resource constraints

## Outputs
- Research report
- Technology comparison matrix
- Best practices document
- Source bibliography
- Recommendations with confidence levels
- Knowledge gap analysis

## Quality Criteria
- Multiple credible sources consulted (≥3)
- Source credibility assessed
- Findings supported by evidence
- Uncertainties documented
- Recommendations are actionable
- Confidence levels stated for each finding

## Metrics
- Source diversity (number of source types)
- Source credibility score
- Research coverage (% of objectives addressed)
- Confidence level of findings
- Time to completion
- Recommendation adoption rate

## Development Path

To improve research capability:
1. Practice systematic search strategies
2. Learn source evaluation techniques
3. Study research methodology
4. Practice synthesis and summarization
5. Seek feedback on research quality
6. Study domain-specific knowledge sources
