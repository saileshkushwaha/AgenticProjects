# Release Management Capability

## Definition
The ability to plan, coordinate, and execute software releases.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can follow release procedures, create notes |
| 2 | Competent | Can coordinate releases, manage scope |
| 3 | Proficient | Can plan releases, manage dependencies |
| 4 | Expert | Can design release processes, multi-team coordination |
| 5 | Master | Can establish organizational release management |

## Scope
**In Scope**: Release planning, feature freeze, RC creation, release notes, deployment coordination
**Out of Scope**: Go/no-go decisions (management responsibility)

## Skills
- **Planning**: Scope definition, timeline creation
- **Coordination**: Cross-team communication, dependency management
- **Documentation**: Release notes, changelogs
- **Execution**: Deployment coordination, monitoring

## Quality Criteria
- Scope defined
- Feature freeze complete
- Testing complete
- Release notes created
