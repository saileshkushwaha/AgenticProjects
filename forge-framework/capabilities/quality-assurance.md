# Quality Assurance Capability

## Definition
The ability to define QA strategies, plan test automation, and improve quality processes.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can follow QA procedures, execute tests |
| 2 | Competent | Can plan testing, define metrics |
| 3 | Proficient | Can define QA strategy, plan automation |
| 4 | Expert | Can design QA processes, lead improvement |
| 5 | Master | Can establish organizational QA practices |

## Scope
**In Scope**: QA strategy, process assessment, test automation planning, metrics, improvement
**Out of Scope**: Test execution (see Testing workflow)

## Skills
- **Strategy**: QA goals, scope, approach definition
- **Assessment**: Process evaluation, gap identification
- **Automation**: Tool selection, strategy, ROI analysis
- **Metrics**: Definition, tracking, improvement

## Quality Criteria
- Strategy defined
- Process assessed
- Automation planned
- Metrics defined
