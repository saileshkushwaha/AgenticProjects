# FinOps Capability

## Definition
The ability to optimize cloud costs and resource utilization.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can read cost reports, identify obvious waste |
| 2 | Competent | Can analyze costs, recommend optimizations |
| 3 | Proficient | Can design FinOps strategies, implement savings |
| 4 | Expert | Can design enterprise FinOps programs |
| 5 | Master | Can establish organizational FinOps practices |

## Scope
**In Scope**: Cost analysis, waste identification, optimization, RI/SP strategy
**Out of Scope**: Budget approval, vendor negotiation (management)

## Skills
- **Analysis**: Cost breakdown, trend analysis
- **Optimization**: Right-sizing, RI/SP, serverless
- **Monitoring**: Alerts, dashboards, budgets
- **Reporting**: Savings, recommendations

## Quality Criteria
- Costs analyzed
- Waste identified
- Optimizations applied
- Savings measured
