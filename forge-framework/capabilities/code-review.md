# Code Review Capability

## Definition
The ability to systematically review code for quality, security, and standards compliance.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can identify obvious issues, follow checklists |
| 2 | Competent | Can review for logic, style, and standards |
| 3 | Proficient | Can review architecture, security, performance |
| 4 | Expert | Can mentor reviewers, design review processes |
| 5 | Master | Can establish organizational review practices |

## Scope
**In Scope**: Static analysis, manual review, standards compliance, feedback
**Out of Scope**: Acceptance/rejection authority (team decision)

## Skills
- **Static Analysis**: Linters, formatters, security scanners
- **Manual Review**: Logic, architecture, patterns, error handling
- **Security Review**: Vulnerability identification, secure coding
- **Feedback**: Actionable, specific, constructive

## Quality Criteria
- Review scope defined
- Static analysis complete
- Standards compliance verified
- Feedback documented and actionable
