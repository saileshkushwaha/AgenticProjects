# Project Planning Capability

## Definition
The ability to plan, estimate, and allocate resources for software projects.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can create basic task lists, follow plans |
| 2 | Competent | Can decompose tasks, estimate effort |
| 3 | Proficient | Can plan sprints, allocate resources, manage risks |
| 4 | Expert | Can plan complex programs, multi-team coordination |
| 5 | Master | Can establish organizational planning practices |

## Scope
**In Scope**: Scope definition, task decomposition, estimation, resource allocation, timeline, risk identification
**Out of Scope**: Budget approval, hiring decisions (management responsibility)

## Skills
- **Decomposition**: WBS, epics, stories, tasks
- **Estimation**: Story points, hours, historical data
- **Allocation**: Resource assignment, skill matching
- **Risk**: Identification, assessment, mitigation

## Quality Criteria
- Scope defined and approved
- Tasks decomposed
- Effort estimated
- Resources allocated
- Timeline created
