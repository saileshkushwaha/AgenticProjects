# Performance Capability

## Definition
The ability to analyze, measure, and optimize system performance.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run basic benchmarks, identify obvious bottlenecks |
| 2 | Competent | Can profile systems, identify bottlenecks |
| 3 | Proficient | Can analyze root causes, implement optimizations |
| 4 | Expert | Can design performance strategies, capacity planning |
| 5 | Master | Can establish organizational performance practices |

## Scope
**In Scope**: Profiling, bottleneck analysis, optimization, benchmarking, capacity planning
**Out of Scope**: Hardware design (consult specialists)

## Skills
- **Profiling**: CPU, memory, I/O, network analysis
- **Bottleneck Analysis**: Hot paths, slow queries, resource contention
- **Optimization**: Caching, indexing, async, scaling
- **Benchmarking**: Load testing, stress testing, comparison

## Quality Criteria
- Baseline established
- Bottlenecks identified and analyzed
- Optimizations implemented
- Improvement measured and documented
