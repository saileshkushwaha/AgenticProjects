# Security Capability

## Definition
The ability to systematically assess, identify, and remediate security vulnerabilities in software systems.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can run basic scans, identify obvious vulnerabilities |
| 2 | Competent | Can conduct assessments, classify vulnerabilities |
| 3 | Proficient | Can perform threat modeling, risk assessment, remediation planning |
| 4 | Expert | Can design security architecture, lead incident response |
| 5 | Master | Can establish organizational security practices |

## Scope
**In Scope**: Threat modeling, vulnerability scanning, risk assessment, remediation planning, security reporting
**Out of Scope**: Physical security, social engineering (consult specialists)

## Skills
- **Threat Modeling**: STRIDE, DREAD, attack surface analysis
- **Vulnerability Assessment**: SAST, DAST, SCA, penetration testing coordination
- **Risk Assessment**: Classification, prioritization, remediation planning
- **Compliance**: SOC2, HIPAA, PCI-DSS, GDPR security requirements

## Quality Criteria
- Threat model complete
- Vulnerabilities classified by severity
- Risk assessment documented
- Remediation plan with timelines
- Compliance requirements met
