# Documentation Capability

## Definition
The ability to create clear, comprehensive technical documentation.

## Proficiency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Novice | Can write basic documentation, follow templates |
| 2 | Competent | Can create user guides, API docs |
| 3 | Proficient | Can plan documentation projects, edit for clarity |
| 4 | Expert | Can design documentation strategies, mentor writers |
| 5 | Master | Can establish organizational documentation practices |

## Scope
**In Scope**: Technical writing, API docs, user guides, runbooks, knowledge base
**Out of Scope**: Marketing content, legal documents (consult specialists)

## Skills
- **Writing**: Clear, concise, structured content
- **Planning**: Audience analysis, content structure
- **Technical**: Code examples, diagrams, API reference
- **Editing**: Clarity, grammar, consistency

## Quality Criteria
- Audience identified
- Content planned and drafted
- Technical review passed
- Published and accessible
